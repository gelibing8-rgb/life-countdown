# ChatGPT Pro 申请说明草稿

## 项目名称

Life Countdown：面向手机与可穿戴设备的人生倒计时开源项目

## 一句话介绍

Life Countdown 默认按 80 岁计算，帮助用户在手机、手表、手环等个人设备上持续看到人生剩余时间，并把长期目标转化为每天最重要的一件事。

## 为什么需要 ChatGPT Pro

本项目不是单纯的倒计时页面，而是一个面向长期个人管理和可穿戴设备生态的开源项目。后续需要持续使用 ChatGPT Pro 完成以下工作：

1. 设计跨平台产品方案，包括 PWA、iOS 快捷指令、Android Health Connect、Apple Watch 和 Wear OS 展示路径；
2. 编写和审查开源代码，保持项目低依赖、可维护、隐私友好；
3. 生成英文 README、贡献指南、隐私说明和开发文档，方便国际化传播；
4. 梳理 Apple Health、Health Connect、可穿戴设备 API 的合规边界；
5. 设计适合普通用户理解的时间可视化、提醒机制和行为反馈；
6. 辅助建立自动化测试、Issue 模板、Release Notes 和 Roadmap。

## 当前已经完成

1. 创建了可运行的 PWA 原型；
2. 默认按 80 岁计算人生倒计时；
3. 支持生日、目标年龄、每日提醒时间设置；
4. 支持本地保存和 JSON 导出；
5. 支持手机添加到主屏幕；
6. 支持每日金句轮换和固定；
7. 支持生成短信、邮件打卡信息；
8. 完成 MIT 开源协议、README 和路线图。

## 后续计划

1. 增加英文界面和国际化；
2. 增加桌面小组件；
3. 增加 iOS 快捷指令集成示例；
4. 增加 Android Health Connect 调研与原型；
5. 增加 Apple Watch / Wear OS 展示方案；
6. 增加隐私白皮书和贡献指南；
7. 发布 GitHub Pages 在线演示。

## 开源价值

Life Countdown 关注的是一个普遍但容易被忽略的问题：如何让人持续感知生命时间的有限性，并用低打扰、隐私友好的方式改善行动选择。

项目可以为以下人群提供价值：

1. 希望建立长期目标感的普通用户；
2. 使用手机、手表、手环进行自我管理的人；
3. 关注数字健康、时间管理和行为设计的开发者；
4. 希望研究 PWA 与可穿戴设备结合方式的开源贡献者。

## 项目原则

1. 隐私优先；
2. 本地优先；
3. 不做成焦虑工具；
4. 不夸大寿命预测；
5. 不采集不必要数据；
6. 先做简单、稳定、可验证的开源版本。
