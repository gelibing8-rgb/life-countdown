# Roadmap

Life Countdown follows a small-step roadmap. Each stage should remain privacy-first, local-first, reviewable, and easy to roll back.

## 0.1.0 PWA 原型

状态：已完成

1. 默认 80 岁倒计时；
2. 生日与目标年龄设置；
3. 人生进度、本年、本月、本周进度；
4. 每日提醒；
5. 本地存储；
6. JSON 导出；
7. Service Worker 离线缓存。

## 0.2.0 开源协作版本

状态：已完成，继续通过 issue 维护

1. 增加英文 README 摘要；
2. 增加贡献指南；
3. 增加隐私、安全和维护说明；
4. 增加 GitHub Pages 部署说明；
5. 增加基础单元测试；
6. 增加 Issue 模板和 PR 模板；
7. 增加无障碍检查清单。

## 0.3.0 安全守护版本

状态：进行中

1. 安全守护模式：每日首次打开自动生成平安打卡；
2. 守护联系人本地保存；
3. 用户确认后生成短信和邮件打卡入口；
4. 一键求救入口：拨打电话、求救短信、求救邮件；
5. 未打卡提醒策略说明；
6. 误报、漏报和隐私泄露风险说明；
7. 独居老人安全守护说明文档；
8. 老人友好字体、按钮和无障碍优化。

## 0.4.0 手机系统集成

1. iOS 快捷指令示例文档；
2. Android 小组件路线调研；
3. 通知策略优化；
4. 本地日历提醒导出；
5. PWA 安装体验优化；
6. 手机端可访问性测试。

## 0.5.0 可穿戴设备集成调研

1. Apple Watch complication 方案；
2. Wear OS tile 方案；
3. Health Connect 权限边界；
4. Apple Health 数据最小化原则；
5. 手环厂商 API 可行性清单；
6. 通过手表、手环确认“今日已活动/已打开/已打卡”的低风险路径；
7. 手表/手环触发求救入口与误触取消机制调研。

## 0.6.0 家庭守护与通知

1. 用户明确授权后的短信、邮件或消息服务接入；
2. 家庭守护端只读查看；
3. 异常提醒与误报控制；
4. 联系人权限撤回；
5. 数据导出与删除；
6. 后端接入前的隐私影响评估。

## 1.0.0 稳定版本

1. 多语言；
2. 可安装在线演示；
3. 完整隐私说明；
4. 完整测试；
5. Release Notes；
6. 开源社区贡献流程；
7. 稳定版本标签和长期维护策略。
